# Lab 0 — Introduction to XSchem and Magic

Ungraded. Work through the manual:
https://uoftasic.github.io/ece334-docs/labs/lab0/

You build every file in this lab yourself; the folder starts almost empty on
purpose. Save your work here:

    lab0_setup/xschem/    schematics and symbols you create
    lab0_setup/magic/     layout you create

Start the environment, then:

    . /foss/designs/common/.designinit
    cd /foss/designs/lab0_setup
    xschem &

The inverter and NAND2 you build here are the same cells that Lab 1 uses from
`common/xschem/`. Compare yours against those when you are done.
