# Lab 2 — starter files

Work in this folder (mounted at `/foss/designs/lab2_layout` inside the container).

**Lab manual:** https://uoftasic.com/ece334-docs/labs/lab2/

Starter SPICE decks are in `spice/`, the LVS wrapper schematic is in
`xschem/nand2_lvs.sch`, and `.magicrc` configures Magic for SKY130. The LVS
helper is shared across the course, so it lives at
`/foss/designs/scripts/run_lvs.sh`. Source the course environment first:

```bash
. /foss/designs/common/.designinit
```
